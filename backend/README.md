A legal engineering project focused on translating regulatory requirements into automated compliance workflows.

- Audit logging

- Privacy compliance automation

## Legal Context

This project explores how obligations under GDPR and KVKK can be translated into software systems.

Examples include:

- Data Subject Access Requests (DSAR)
- Consent management
- Auditability
- Data retention controls
